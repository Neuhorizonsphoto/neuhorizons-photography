# Neuhorizons Photography website

This is a deployment-ready static website.

## Upload to GitHub
Upload the **contents of this folder** to the root of your existing repository.  
The repository root must show `index.html`, `styles.css`, `script.js`, `vercel.json`, and the `assets` folder.

## Redeploy on Vercel
After committing the files to the `main` branch, Vercel should redeploy automatically.

If you manually import the repository:
- Framework Preset: **Other**
- Root Directory: `./`
- Build Command: leave blank
- Output Directory: leave blank

## Contact form
The form currently opens an email addressed to:

`info@neuhorizonsphotography.com`

Replace that address in `index.html` if you choose another inbox.
